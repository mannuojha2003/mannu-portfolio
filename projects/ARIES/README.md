# 🔬 ARIES: Scientific Radiation Integration Tool

Developed during a research internship at the **Aryabhatta Research Institute of Observational Sciences (ARIES)**, this suite of Python tools is designed for atmospheric research, specifically focusing on processing High Energy Pulse LiDAR data.

## 🚀 Overview

The primary goal of this tool is to automate the processing of `.out` files generated by instrumentation hardware. It sorts complex radiation data and calculates integrated values across specific wavelength ranges (UV, Visible, and IR) using numerical integration methods.

## 🛠️ Key Functionalities

- **Numerical Integration**: Implements the **Trapezoidal Rule** using `numpy.trapz` to calculate total radiation energy over customizable wavelength bands.
- **Data Sorting & Aggregation**: Automatically scans directories for `.out` files, extracts temporal data (Day/Time), and groups radiation metrics (Radiation 1 & 2).
- **Automated Reporting**: Generates multi-sheet Excel workbooks (`integrated_radiation.xlsx`) with clean, professional data presentation for scientific analysis.
- **Portable Architecture**: Uses relative pathing to ensure the tool runs seamlessly across different workstations without configuration overhead.

## 📊 Wavelength Ranges
The tool integrates over the following standard atmospheric research bands:
- **UV**: 260nm – 380nm
- **Visible**: 381nm – 700nm
- **IR**: 701nm – 2600nm
- **Full Spectrum**: 260nm – 2600nm

## ⚙️ Requirements

- Python 3.x
- `pandas`
- `numpy`
- `openpyxl`

## 📖 Usage

1. Place your `.out` raw data files in the `/input` directory.
2. Run the integration script:
   ```bash
   python Integrating3.py
   ```
3. Find the processed results in the `/output` directory.
